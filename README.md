## Instrucciones de Instalación y Ejecución.

 Para clonar y correr este proyecto de manera local en tu máquina, seguí estos pasos:

1.  Clonar el repositorio:
   en la terminal
   git clone [https://github.com/DavidNieto-2012/TP-Integrador-final---WEB-2.git](https://github.com/DavidNieto-2012/TP-Integrador-final---WEB-2.git)

2. Instalar dependencias
    npm install

3. Instalar React Router
    npm install react-router-dom

4. Correr proyecto
    npm run dev
